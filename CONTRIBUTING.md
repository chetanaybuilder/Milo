# Contributing to MILO

We welcome contributions! Please follow these guidelines:

1. **Issues**: Open an issue to discuss proposed changes before writing code.
2. **Pull Requests**:
   - Keep PRs focused on a single change.
   - Write clean, well-documented code.
   - Ensure all tests pass (`pytest` in backend, `npm run build` in frontend).
   - Do not commit secrets or API keys.
3. **Style**: 
   - Python: PEP 8, add type hints.
   - JS/React: Use modern hooks, avoid inline scripts.
